# Accelerated vector databases with NVIDIA cuVS

Vector databases are a hot topic today for semantic search, and they're powering everything from generative AI workloads to recommender systems. These notebooks provide instruction for optimizing vector database workloads on the GPU, including (1) optimizing ingest and index creation at scale, (2) choosing the best indexes for your data, and (3) tuning the indexes to trade off search speed and quality.

This talk was delivered at [ASU GPU Day 2025](https://asuevents.asu.edu/event/gpu-day-2025).
